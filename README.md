# Artefact AI – Frontend

This is the **React-based frontend interface** for the **Artefact AI RAG Chatbot**.

The frontend provides a chat interface where users can ask questions about classical literature such as:

- Iliad
- Odyssey
- Bhagavad Gita
- Ramayana

The interface sends user queries to the backend API and displays AI-generated responses.

---

# Project Overview

Artefact AI is a **Retrieval-Augmented Generation (RAG) chatbot** designed to answer questions about classical texts using a combination of:

- Vector search (FAISS)
- Context retrieval
- Large Language Models (LLMs)

The frontend provides a **ChatGPT-style interface** for interacting with the system.

---

# System Architecture

User Interface (React)
↓
API Request
↓
Flask Backend
↓
Vector Search (FAISS)
↓
Context Retrieval
↓
Groq LLM (Llama 3.1)
↓
Generated Response
↓
Displayed in Chat UI
